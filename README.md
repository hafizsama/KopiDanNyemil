
# KopiDanNyemil ☕

Aplikasi pemesanan kopi dan camilan berbasis Android yang memudahkan pengguna melihat menu, melakukan pemesanan, dan mengelola informasi akun.

## Deskripsi

KopiDanNyemil merupakan proyek UTS mata kuliah Pemrograman Mobile yang dikembangkan menggunakan Android Studio dengan bahasa pemrograman Kotlin.

## Fitur Aplikasi

- Splash Screen
- Registrasi akun
- Login pengguna
- Halaman Home
- Daftar menu kopi dan camilan
- Profil pengguna
- Alamat pengiriman
- Konfirmasi pesanan

## Teknologi

- Android Studio
- Kotlin
- XML Layout
- SharedPreferences
- Android SDK

## Penyimpanan Data

Aplikasi menggunakan SharedPreferences untuk menyimpan data akun secara lokal. Data menu dan pesanan menggunakan data dummy.

## Cara Menjalankan

1. Clone repository:

   ```bash
   git clone https://github.com/hafizsama/KopiDanNyemil.git
   ```

2. Buka folder project melalui Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Hubungkan perangkat Android atau jalankan emulator.
5. Tekan tombol Run.
